# คู่มือผู้ใช้ WJ DB Studio (ภาษาไทย)

> WJ DB Studio — โปรแกรมจัดการฐานข้อมูล MySQL และ MariaDB
> พัฒนาโดย **Weeradech Jessadarom** · License: MIT

## 1. การติดตั้ง

ไม่ต้องติดตั้ง — เลือกไฟล์จากหน้า [Releases](https://github.com/weeradech/wj-db-studio/releases):

| ไฟล์ | เหมาะกับ |
|---|---|
| `WJ-DB-Studio-x.y.z-Portable.exe` | ใช้งานทันที ไม่ต้องติดตั้ง (วางในโฟลเดอร์/แฟลชไดรฟ์ก็ได้) |
| `WJ DB Studio Setup x.y.z.exe` | ติดตั้งถาวรพร้อม shortcut บนเดสก์ท็อป |

ข้อมูลการตั้งค่าและการเชื่อมต่อทั้งหมดเก็บที่:
`%APPDATA%\WJ DB Studio\config.json` (โปรแกรม portable ก็ใช้ตำแหน่งนี้เช่นกัน)

## 2. เชื่อมต่อฐานข้อมูล

1. กดปุ่ม **เชื่อมต่อ** ด้านบน หรือ **+** ที่แผงด้านซ้าย
2. กรอกข้อมูล:
   - **ชื่อ** — ชื่อเรียก เช่น "ระบบขาย-Production"
   - **กลุ่ม** — (ไม่บังคับ) จัดกลุ่มการเชื่อมต่อ
   - **Host / Port / Username / Password**
   - **SSL/TLS** — ติ๊กเพื่อเข้ารหัสการเชื่อมต่อ (ใส่ไฟล์ CA ได้)
   - **SSH Tunnel** — เมื่อฐานข้อมูลอยู่หลังเซิร์ฟเวอร์ SSH (ใส่ host/port/user และรหัสผ่านหรือ private key)
3. กด **ทดสอบ** — ถ้าขึ้น "เชื่อมต่อสำเร็จ" ให้กด **บันทึก**
4. ในแผงด้านซ้าย **ดับเบิลคลิก** ชื่อการเชื่อมต่อเพื่อเชื่อมต่อ (จุดเขียว = เชื่อมต่ออยู่)

> 💡 ถ้า error แสดงคำแนะนำแบบ "หมอ error" ด้านล่างข้อความ error ทันที

## 3. สำรวจออบเจกต์

แผงด้านซ้ายแสดง: การเชื่อมต่อ → ฐานข้อมูล → (ตาราง / วิว / SP / ฟังก์ชัน / ทริกเกอร์ / อีเวนต์)

- กด **ลูกศร** เพื่อขยาย, **ดับเบิลคลิกตาราง** เพื่อเปิดข้อมูล
- **คลิกขวา** ที่แต่ละรายการเพื่อดูเมนู: ดู DDL, ออกแบบตาราง, นำเข้า, สำรอง, Truncate, Drop, เปลี่ยนชื่อ
- ช่องค้นหาด้านบนใช้กรองชื่อออบเจกต์ข้ามทุกกลุ่ม
- สร้างฐานข้อมูลใหม่ได้ที่ปุ่ม **ฐานข้อมูลใหม่** ใต้รายการฐานข้อมูล

## 4. เขียนและรัน SQL

- **Ctrl+T** เปิดแท็บ SQL ใหม่
- พิมพ์คำสั่งแล้วกด **Ctrl+Enter** (หรือปุ่ม ▶)
- **Ctrl+Shift+Enter** รันเฉพาะข้อความที่เลือก
- รันได้หลายคำสั่งพร้อมกันคั่นด้วย `;` — ผลลัพธ์แยกเป็นแท็บ Result 1, 2, …
- **Ctrl+Space** ช่วยเติม: คีย์เวิร์ด SQL, ชื่อตาราง, ชื่อคอลัมน์ (ดึงจากสคีมาจริง)
- **Ctrl+/** คอมเมนต์/ปลดคอมเมนต์บรรทัด
- ปุ่ม **จัดรูปแบบ SQL** ช่วยจัดย่อหน้าคำสั่ง
- แผงล่าง: **ข้อความ** (log), **ประวัติ** (คลิกเพื่อกลับมาใช้), **ตัวอย่าง SQL** (บันทึกคำสั่งที่ใช้บ่อย — คลิกขวาเพื่อลบ)

## 5. ดูและแก้ไขข้อมูล

เมื่อเปิดตาราง (ดับเบิลคลิก):

- กรองด้วย WHERE ตรง ๆ ในช่อง filter เช่น `price > 100 AND status = 1`
- คลิกหัวคอลัมน์เพื่อเรียง (ORDER BY)
- **ดับเบิลคลิกเซลล์** เพื่อแก้ไข → Enter ยืนยัน
- **เพิ่มแถว / ลบแถว** จากปุ่มบนแถบเครื่องมือ
- จำนวนที่ยังไม่บันทึกจะขึ้นเป็น badge เหลือง กด **บันทึกการแก้ไข** เพื่อ apply (UPDATE/INSERT/DELETE อ้างอิง Primary Key — ตารางไม่มี PK จะใช้ทุกคอลัมน์จับคู่)
- เว้นช่องว่าง = บันทึกเป็น NULL
- คลิกขวาที่เซลล์: คัดลอกค่า/แถว JSON/คำสั่ง INSERT

## 6. ออกแบบตาราง

คลิกขวาตาราง → **ออกแบบตาราง** หรือสร้างใหม่จากฐานข้อมูล:

- แก้ชื่อ/ชนิด/NULL/ค่าเริ่มต้น/Auto Increment/คำอธิบายของคอลัมน์
- ติ๊กช่องแรกของคอลัมน์เพื่อตั้ง Primary Key
- เพิ่มดัชนี (UNIQUE ได้) และ Foreign Key (ระบุ ON DELETE/ON UPDATE)
- ปุ่ม **ดู SQL** พรีวิวคำสั่งก่อนกด **บันทึก**

## 7. นำเข้า / ส่งออก / สำรอง

### นำเข้า (ปุ่ม "นำเข้า")
- **CSV/TSV** — เลือกตัวคั่น (`,` `;` TAB `|`), แถวแรกเป็นชื่อคอลัมน์, ล้างตารางก่อนนำเข้า (ตัวเลือก)
- **JSON** — ไฟล์ array เช่น `[{"id":1,"name":"A"}]`
- **SQL** — รันไฟล์ `.sql` ทั้งไฟล์ (ใช้กู้คืน backup ได้)

### ส่งออก
- จากผลลัพธ์ SQL หรือตารางที่เปิดอยู่ → ปุ่ม **ส่งออก** → เลือก CSV / JSON / SQL INSERT
- ไฟล์เขียนลงดิสก์แบบสตรีม รองรับตารางใหญ่หลายล้านแถว

### สำรองข้อมูล (ปุ่ม "สำรอง")
- เลือกฐานข้อมูล (เว้นว่างช่องตาราง = ทุกตาราง) และตัวเลือก โครงสร้าง/ข้อมูล/วิว
- ได้ไฟล์ `.sql` แบบ mysqldump พร้อม `SET FOREIGN_KEY_CHECKS=0` ที่หัวไฟล์

## 8. เครื่องมือเซิร์ฟเวอร์

- **เซิร์ฟเวอร์** — แดชบอร์ด: เวอร์ชัน, ชนิด (MySQL/MariaDB), uptime, การเชื่อมต่อ, ขนาดฐานข้อมูลรายตัว
- **Process List** — ดูทุก process คลิกขวาเพื่อ **Kill** (ตัดการเชื่อมต่อ) หรือ **Kill Query** (เฉพาะคำสั่งที่รันค้าง)
- **ตัวแปรระบบ / สถานะ** — ค้นหาตัวแปรเช่น `max_connections`, `innodb_buffer_pool_size`
- **ผู้ใช้** — สร้าง/ลบผู้ใช้ (`user@host`), ตั้งรหัสผ่าน, ดู GRANT และให้สิทธิ์ global

## 9. การตั้งค่า (Ctrl+,)

- ภาษา ไทย/English · ธีม มืด/สว่าง
- ขนาดฟอนต์หน้าจอ / ตัวแก้ไข SQL
- แถวต่อหน้า (default 500) · หมดเวลาคำสั่ง (default 30 วินาที)
- ตรวจสอบการอัปเดตอัตโนมัติ · ยืนยันก่อนคำสั่งลบข้อมูล · ช่วยเติม SQL

## 10. ความปลอดภัย

- รหัสผ่านถูกเข้ารหัสด้วย **safeStorage ของ OS** (Windows: DPAPI) เก็บในเครื่องเท่านั้น
- ไม่มีการส่งข้อมูลออกนอกเครื่อง (ไม่มี telemetry/analytics)
- ตัวเชื่อมต่อใช้ prepared statements สำหรับการแก้ไขข้อมูลใน grid

## 11. แก้ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| `Access denied` | ตรวจ username/password และ Host ของ user ใน `mysql.user` (ลอง `%` หรือ IP ของเครื่อง) |
| `ECONNREFUSED` | เซิร์ฟเวอร์ไม่ได้เปิด หรือ port ผิด ตรวจ `bind-address` |
| Timeout | ไฟร์วอลล์/เครือข่าย หรือเพิ่มค่าหมดเวลาในการตั้งค่า |
| `Unknown database` | สร้างฐานข้อมูลก่อน (ปุ่มฐานข้อมูลใหม่) |
| เชื่อมต่อหลุดบ่อย | `wait_timeout` ของเซิร์ฟเวอร์สั้น — กดเชื่อมต่อใหม่จากแผงด้านซ้าย |
| ภาษาไทยแสดง `???` | ใช้ charset `utf8mb4` ตั้งแต่ตอนสร้างตาราง/ฐานข้อมูล |
