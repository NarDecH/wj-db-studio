## 📦 ฟังก์ชันครบถ้วน

- **จัดการการเชื่อมต่อ** — บันทึกได้ไม่จำกัด จัดกลุ่มได้, SSL/TLS (ใส่ CA เองได้), SSH Tunnel, ทดสอบการเชื่อมต่อก่อนบันทึก
- **สำรวจออบเจกต์** — ฐานข้อมูล ตาราง วิว stored procedure function trigger event พร้อมจำนวนแถวและขนาด
- **ตัวแก้ไข SQL** — ไฮไลต์ไวยากรณ์, ช่วยเติมคำอ้างอิงสคีมาจริง (Ctrl+Space), รันหลายคำสั่งพร้อมกัน, ผลลัพธ์หลายแท็บ, ประวัติคำสั่ง, ตัวอย่าง SQL ที่บันทึกไว้, จัดรูปแบบ SQL
- **ตารางข้อมูล** — กรองด้วย WHERE, เรียง, แบ่งหน้า; แก้ไขในเซลล์ (INSERT/UPDATE/DELETE อ้างอิง Primary Key), จัดการ NULL, คัดลอกเป็น JSON/INSERT
- **ออกแบบตาราง** — เพิ่ม/แก้คอลัมน์, primary key, ดัชนี, foreign key พร้อมพรีวิว SQL ที่จะรัน
- **นำเข้า** — CSV/TSV (เลือกตัวคั่น/แถวหัวตาราง), JSON array, ไฟล์ .sql
- **ส่งออก** — CSV, JSON, SQL INSERT; ไฟล์ใหญ่สตรีมลงดิสก์โดยไม่กินแรม
- **สำรองข้อมูล** — ไฟล์ .sql แบบ mysqldump (โครงสร้าง + ข้อมูล + วิว) ทั้งฐานข้อมูลหรือเฉพาะตาราง; กู้คืนผ่านเมนูนำเข้า
- **เครื่องมือเซิร์ฟเวอร์** — แดชบอร์ด (เวอร์ชัน/uptime/การเชื่อมต่อ/ขนาด), Process List พร้อม KILL, ค้นหาตัวแปรระบบและสถานะ
- **ผู้ใช้และสิทธิ์** — สร้าง/ลบผู้ใช้, ตั้งรหัสผ่าน, GRANT สิทธิ์ระดับ global
- **ระบบ config สมบูรณ์** — ธีม ภาษา ฟอนต์ จำนวนแถวต่อหน้า หมดเวลา นโยบายยืนยันการลบ; เก็บในเครื่อง
- **สองภาษา** — ไทย/อังกฤษ สลับได้ทันที

## 🚀 เริ่มใช้งาน

1. ดาวน์โหลด **`WJ-DB-Studio-x.y.z-Portable.exe`** (หรือตัวติดตั้ง) จาก [**Releases**](../../releases)
2. เปิดโปรแกรม กด **เชื่อมต่อ** → กรอกข้อมูล MySQL/MariaDB → **ทดสอบ** → **บันทึก**
3. ดับเบิลคลิกการเชื่อมต่อในแผงด้านซ้าย ขยายฐานข้อมูล ดับเบิลคลิกตาราง — เสร็จ

> เครื่องที่รันโปรแกรมไม่ต้องติดตั้งอะไรเพิ่ม ต้องการเพียงเน็ตเวิร์กที่ติดต่อกับเซิร์ฟเวอร์ฐานข้อมูล

| `Ctrl+T` | แท็บ SQL ใหม่ |

| `Ctrl+Shift+Enter` | รันเฉพาะที่เลือก |
| `Ctrl+Space` | ช่วยเติมคำ |

| `F5` | รีเฟรช |
| `Ctrl+,` | ตั้งค่า |

## 🛠 สำหรับนักพัฒนา

```bash
npm install     # ติดตั้ง dependencies
npm start       # รันโหมดพัฒนา
npm run selftest
npm run dist    # build ตัวติดตั้ง + portable exe สำหรับ Windows
```

ดูระบบ release อัตโนมัติผ่าน GitHub Actions ได้ที่ [docs/BUILD.md](docs/BUILD.md)
